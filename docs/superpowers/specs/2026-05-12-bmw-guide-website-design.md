# 黑神话：悟空攻略站 — 设计规格文档

**日期**：2026-05-12
**状态**：已审批
**类型**：MVP 多页静态网站

---

## 1. 概述

为**黑神话：悟空**打造的中英双语游戏攻略网站，面向外国休闲及新手玩家。MVP 阶段以流程攻略和 Boss 打法为核心内容，采用暗黑东方美学视觉设计。

### 目标用户
- 刚接触动作 RPG / 魂系游戏的外国玩家
- 需要游戏机制、Boss 打法、流程推进方面的指导
- 以英文为主要语言；中文文化术语需附解释

### 成功标准
- 沉浸式暗黑东方美学
- 章节与 Boss 页面间导航清晰
- 中英文无缝切换
- 移动端适配
- 零构建依赖——双击 HTML 文件即可打开

### MVP 范围
- **首页**：完整布局 + 示例数据
- **Boss 列表页**（`bosses/index.html`）：3 个 MVP Boss 的简单列表（暂无搜索/筛选）

- 其余页面后续补充

## 3. 页面布局

| 区域 | 说明 |

| **侧边栏** | 吸顶式章节内目录导航 |

### 3.3 Boss 详情页（bosses/xxx.html）

| 区域 | 说明 |
|------|------|
| **Boss 头部** | 头像 + 双语名称（英文 / 中文） |

| **打法策略** | 推荐装备 + 阶段分析 + 攻击模式说明 |
| **实用技巧** | 要点列表形式 |

### 3.4 公共组件

| 组件 | 说明 |
|------|------|
| **导航栏** | Logo + 主导航（Walkthrough / Bosses）+ 语言切换（EN / 中文） |
| **页脚** | 版权声明、免责声明、社交媒体链接占位 |

## 4. 视觉设计

### 4.1 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#0a0a0a` | 近纯黑，沉浸感 |
| 次背景/卡片 | `#1a1a1a` | 深灰，层次感 |
| 主强调色 | `#c9a84c` | 金色——呼应金箍棒 |
| 次强调色 | `#8b2500` | 暗红——中国红 |
| 正文文字 | `#e8e0d0` | 暖白，不刺眼 |
| 次要文字 | `#9a9080` | 暖灰（卡片背景上满足 WCAG AA 标准） |
| 边框/分隔 | `#2a2520` | 暗棕，东方古朴感 |

### 4.2 字体

| 用途 | 字体 | 回退栈 |
|------|------|--------|
| 标题（英文） | Cinzel | `'Cinzel', 'Georgia', 'Times New Roman', serif` |
| 标题（中文） | Noto Serif SC | `'Noto Serif SC', 'SimSun', 'STSong', serif` |
| 正文（英文） | Inter | `'Inter', -apple-system, 'Segoe UI', Helvetica, sans-serif` |
| 正文（中文） | Noto Sans SC | `'Noto Sans SC', 'Microsoft YaHei', 'PingFang SC', sans-serif` |

### 4.3 设计元素

- **云纹装饰**：SVG 云纹作为分隔线和角落装饰
- **金色细线**：卡片和内容块的金色边框线
- **渐变遮罩**：图片上叠加暗色渐变，确保文字可读
- **悬停效果**：卡片轻微上浮 + 金色边框高亮
- **无重度动效**——仅使用轻量、性能友好的过渡动画

### 4.4 响应式断点

| 断点 | 目标设备 |
|------|----------|
| 1200px+ | 桌面端（主要目标） |
| 768px–1199px | 平板 |
| < 768px | 手机（主导航折叠为汉堡按钮，展开为下滑菜单） |

**攻略页 TOC 侧边栏（手机端）**：折叠为页面内容顶部的手风琴组件，点击展开。

## 5. 双语实现

### 语言切换机制
- 导航栏固定切换按钮：`EN | 中文`
- HTML 元素通过 `data-lang="en"` / `data-lang="zh-CN"` 属性标记
- 语言容器必须设置 `lang="en"` / `lang="zh-CN"` HTML 属性
- 隐藏的语言元素必须由 JS 设置 `aria-hidden="true"`
- JS 控制各语言元素的显示/隐藏
- `<html lang>` 属性由 JS 切换为当前活跃语言
- 默认语言跟随浏览器 `navigator.language`
- URL 不变——所有内容已在 HTML 中预渲染
- 中文变体：简体中文（zh-CN）

### 内容规范
- 术语首次出现格式：`English (中文)`，如 "Yaoguai (妖怪)"
- Boss 名称双语显示："Black Bear Spirit (黑熊精)"
- 难度使用通用星级图标（1-5 星）
- 提示框双语标注："Before You Go / 出发前"

## 6. 技术约束

- **无构建工具**——纯 HTML、CSS、JavaScript
- **无框架**——仅使用原生 JS
- **图片**——MVP 阶段使用占位图；正式版使用 WebP + lazy loading
- **字体**——通过 Google Fonts CDN 加载
- **浏览器支持**——现代浏览器（Chrome、Firefox、Safari、Edge 最近 2 个版本）

### 无障碍（WCAG 2.1 AA）
- 所有颜色组合满足正文 4.5:1 对比度要求
- 所有图片具有描述性 `alt` 属性
- 页面首个可聚焦元素为"跳至正文"链接
- 键盘可操作：导航栏、语言切换、汉堡菜单均可通过 Tab/Enter 操作
- 所有交互元素具有 focus-visible 样式
- 语言容器正确使用 `lang` 和 `aria-hidden` 属性

### 404 错误页
- 根目录下的 `404.html`，包含公共导航栏/页脚
- 居中双语提示："Page not found / 页面未找到"
- 链接回首页
